# お母さんの愛AI ドリル

〜中途半端な教育ママの試行錯誤〜

中学受験や定期テストに伴走する親が、AI（Claude）を上手に使って、問題づくりの負担を減らすためのリポジトリです。
作った問題は、スマホで解ける一問一答として、無料で公開しています。

> 📖 **note から来てくださった方へ**
> 記事はこちら → 【noteのURLをここに貼る】
> 教材の一覧は、公開ページ（トップページ）から選べます → 【GitHub PagesのURLをここに貼る】

---

## このリポジトリについて

- 対象は、「うちは真ん中あたりで、ちょっと頑張っている」という、いわゆるボリュームゾーンのお子さんと、その親御さんです。
- 難関校の攻略法ではなく、**親が少ない手間で回せる復習教材づくり**を目指しています。
- 完璧ではない私の、失敗も含めた試行錯誤を、そのまま公開しています。

- **フラッシュカード**: カードをタップして答えを見て、「わかった」「まちがえた（印）」を選びます。印のカードだけ復習できます。小学生向けは、正答数と時間から、レベルが出ます。
- **ノート記述**: 答えをノートに書いて、自分で正解・不正解を選びます。
- 印や記録は、お使いのブラウザの中だけに保存されます。名前などの入力欄はありません。

## フォルダの構成

```
index.html                     トップページ（教材の一覧）
elementary/                    小学生向け
  society/  history/  geography/
  science/  life/
  japanese/  vocabulary/
junior/                        中学生向け
  science/  chemistry/
docs/                          ルールや設定のメモ（予定）
```

教材は、`学年/教科/分野/教材名/index.html` の形で置きます。1教材につき、HTML 1ファイルで動きます。

## 教材を足すとき

1. 上の構成に従って、新しいフォルダに `index.html` を置きます。
2. トップページ（`index.html`）の `QUIZ` に、1行足します。
3. この README の「教材の一覧」にも、1行足します。

## 使うときの3つの約束

1. **解答は、必ず親が確認する**: AIは自信満々に間違えることがあります。
2. **過去問や塾のテキストを、そのまま入力・転載しない**: 著作権のためです。事実（人名・年号・用語）は自由に使えますが、問題文は、自分の言葉で作り直してください。
3. **お子さんの名前や学校名など、個人情報を入力しない・写さない**: 教材の写真を使うときは、名前などが写っていないか確認してください。
